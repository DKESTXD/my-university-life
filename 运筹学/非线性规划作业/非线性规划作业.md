## 1 列写模型并求解

<img src="D:\新建文件夹 (3)\WeChat Files\wxid_uzqin1xmai4h22\FileStorage\Temp\23db8014b842ff085e29d33d28c4344.png" alt="23db8014b842ff085e29d33d28c4344" style="zoom: 67%;" />

本题目是一个非线性规划问题，同时也是二次规划问题，依照题意列出的模型为
$$
max\ \ \ \ \ \ \ 3x_1-(x_1-1)^2+3x_2-(x_2-2)^2\\
s.t.\ \ \ \ \ \ \ \ 4x_1+x_2\leq20\\
\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ x_1+4x_2\leq20\\
\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ x_1,x_2\geq 0
$$
转化为标准形式：
$$
min\ \ \ \ \ \ \ -3x_1+(x_1-1)^2-3x_2+(x_2-2)^2\\
s.t.\ \ \ \ \ \ \ \ -4x_1-x_2+20\geq0\\
\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ -x_1-4x_2+20\geq0\\
\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ x_1,x_2\geq 0
$$
因为是个二次规划问题，没有那么复杂，因此可以用**K-T**条件来求解

对目标函数求梯度
$$
▽f(x_1,x_2)=(2x_1-5,2x_2-7)
$$


对约束条件求梯度
$$
▽g_1(x_1,x_2)=(-4,-1)\\
▽g_2(x_1,x_2)=(-1,-4)\\
▽g_3(x_1,x_2)=(1,0)\\
▽g_4(x_1,x_2)=(0,1)\\
$$
假设KT点为x\*，引入拉格朗日乘子$$\mu_1^*,\mu_2^*,\mu_3^*,\mu_4^*$$
$$
2x_1-5+4\mu_1^*+\mu_2^*-\mu_3^*=0\\
2x_2-7+\mu_1^*+4\mu_2^*-\mu_4^*=0\\
\mu_1^*(-4x_1-x_2+20)=0\\
\mu_2^*(-x_1-4x_2+20)=0\\
\mu_3^*x_1=0\\
\mu_4^*x_2=0\\
\mu_1^*,\mu_2^*,\mu_3^*,\mu_4^*\geq0
$$
因为$$\mu_3^*,\mu_4^*$$对应约束比较特殊，首先考虑这两个

1. 当$$\mu_3^*>0,\mu_4^*>0$$，只能有$$x_1=0,x_2=0$$，此时肯定满足约束条件，目标函数值为-5

2. 当$$\mu_3^*,\mu_4^*$$存在一个大于0一个等于0时，就说明$$x_1,x_2$$中至少存在一个为0，此时如果$$\mu_1^*,\mu_2^*$$同时大于0，因为其对应的两个约束函数常数项一样但是倍数不一样，会导致无解。
   因此当$$\mu_3^*,\mu_4^*$$存在一个大于0一个等于0时，只有$$\mu_1^*,\mu_2^*$$是全等于0的情况下$$x_1,x_2$$是非全零解。

   - 当$$\mu_3^*=0,\mu_4^*>0$$，此时$$x2=0$$

     ​	当$$\mu_1^*=0,\mu_2^*=0$$，解得$$\mu_4^*=-7$$不满足第三个条件

     ​	当$$\mu_1^*>0,\mu_2^*=0$$，解得$$x_1=5,\mu_1^*=-1.25$$不满足第三个条件

     ​        当$$\mu_1^*=0,\mu_2^*>0$$，解得$$x_1=20,\mu_2^*=-35$$不满足第三个条件

   - 当$$\mu_3^*>0,\mu_4^*=0$$，此时$$x1=0$$

      	当$$\mu_1^*=0,\mu_2^*=0$$，解得$$\mu_3^*=-5$$不满足第三个条件

     ​	 当$$\mu_1^*>0,\mu_2^*=0$$，解得$$x_2=20,\mu_1^*=-33$$不满足第三个条件

     ​         当$$\mu_1^*=0,\mu_2^*>0$$，解得$$x_2=5,\mu_2^*=-0.75$$不满足第三个条件

3. 当$$\mu_3^*=0,\mu_4^*=0$$，两个都是非零解

   - 当$$\mu_1^*=0,\mu_2^*=0$$，$$x_1=2.5,x_2=3.5$$，满足约束条件，此时目标函数值为 -13.5
   - 当$$\mu_1^*>0,\mu_2^*=0$$，解得$$\mu_1^*=-\frac{13}{17}$$，不满足条件三
   - 当$$\mu_1^*=0,\mu_2^*>0$$，解得$$\mu_2^*=-\frac{7}{17}$$，不满足条件三
   - 当$$\mu_1^*>0,\mu_2^*>0$$，解得$$x_1=4,x_2=4$$，满足约束条件，此时目标函数值-11



因此共有三个KT点，其中$$x_1=2.5,x_2=3.5$$时，目标函数值最小，为最优解，最大收益为13.5百万元



## 2 按如下题意建立优化命题

<img src="D:\新建文件夹 (3)\WeChat Files\wxid_uzqin1xmai4h22\FileStorage\Temp\5b522258c5e72fe852413aead80816a.png" alt="5b522258c5e72fe852413aead80816a" style="zoom:50%;" />

假设这n次的x序列为$$\{x_1,x_2,...,x_n,x_{n+1}\}$$，y序列为$$\{y_1,y_2,...,y_n\}$$

其中$$x_2=ay_1+b(x_1-y_1),x_3=ay_2+b(x_2-y_2)$$，即$$x_{i+1}=ay_i+b(x_i-y_i)=bx_i+(a-b)y_i$$

因为yi是决策变量，而目标函数和约束条件中一定会出现xi的序列，因此需要用yi和已知的x1来表示x序列中每个值。

由递推关系，我们可以获得
$$
\begin{flalign}
&x_1=x_1\\
&x_2=bx_1+(a-b)y_1\\
&x_3=b(bx_1+(a-b)y_1)+(a-b)y_2=b^2x_1+b(a-b)y_1+(a-b)y_2\\
&x_4=b^3x_1+b^2(a-b)y_1+b(a-b)y_2+(a-b)y_3\\
&x_{i+1}=b^ix_1+(a-b)\sum^{i}_{k=1}b^{i-k}y_k&
\end{flalign}
$$
那么目标函数可以写作
$$
f(y_1,...,y_n)=\sum^n_{i=1}g(y_i)+\sum^n_{i=1}h(x_i-y_i)
$$
约束条件有：

非负约束$$x_i\geq 0,y_i\geq 0$$

原料总量约束$$y_i\leq x_i$$

理论上只要满足原料总量约束，$$x_i$$必定为非负的



那么优化模型可以写为：
$$
\begin{flalign}
&max\ \ \ \ \ f(y_1,...,y_n)=\sum^n_{i=1}g(y_i)+\sum^n_{i=1}h(x_i-y_i)\\
&s.t.\ \ \ \ \ \ y_1\leq x_1\\
&\ \ \ \ \ \ \ \ \ \ \ \ \ y_i-(a-b)\sum^{i-1}_{k=1}b^{i-k-1}y_k\leq b^{i-1}x_1\ \ \ \ i=2,...,n\\
&\ \ \ \ \ \ \ \ \ \ \ \ \ y_i\geq 0\ \ \ \ \ i=2,...,n
\end{flalign}
$$
标准形式写为：
$$
\begin{flalign}
&min\ \ \ \ \ -f(y_1,...,y_n)=-(g(y_1)+h(x_1-y_1))-(\sum^n_{i=2}g(y_i)+\sum^n_{i=2}h(b^{i-1}x_1+(a-b)\sum^{i-1}_{k=1}b^{i-k-1}y_k-y_i))\\
&s.t.\ \ \ \ \ \ x_1-y_1\geq 0\\
&\ \ \ \ \ \ \ \ \ \ \ \ \ b^{i-1}x_1-y_i+(a-b)\sum^{i-1}_{k=1}b^{i-k-1}y_k\geq 0\ \ \ \ i=2,...,n\\
&\ \ \ \ \ \ \ \ \ \ \ \ \ y_i\geq 0\ \ \ \ \ i=2,...,n
\end{flalign}
$$
