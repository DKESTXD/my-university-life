## 1 校验和

```c
#include <reg51.h>

void main(){
	unsigned char A[15]={27,5,32,47,38,235,79,17,187,58,23,35,211,104,9};
	unsigned char data *pRam;
	int data *pSum;
	int i=0;
	int sum=0;
	pRam=0x30;
	pSum=0x3F;
	for (i=0;i<15;i++){
		*pRam=A[i];
		pRam++;
	}
	for (i=0;i<15;i++){
		sum+=A[i];
	}
	*pSum=sum;
	while(1);
}
```

由于int类型占两个字节，用int定义数组A会导致0x3F位置被占，故用unsigned char定义。如果用char会有一位变为符号位，使表达的整数值有变。

内存占用：从RAM的0x30——0x3E为数组内存。

## 2 取最小值

```c
#include <reg51.h>

void main(){
	unsigned char A[15]={27,5,32,47,38,235,79,17,187,58,23,35,211,104,9};
	unsigned char data *pRam;
	unsigned char data *pMin;
	int i=0;
	unsigned char t=A[0];
	pRam=0x30;
	pMin=0x3F;
	for(i=0;i<15;i++){
		*pRam=A[i];
		pRam++;
	}
	for(i=0;i<15;i++){
		if(A[i]<t) {t=A[i];}
	}
	*pMin=t;
	while(1);
}
```
