### 1. K近邻聚类

原理：给定一个训练数据集，对新的输入实例，在训练数据集中找到与该实例最邻近的K个实例，这K个实例的多数属于某个类，就把该输入实例分类到这个类中，即“少数服从多数”。

```py
import numpy as np
def get_dist(a_arr, b_arr, method=True):
    dis_arr = np.abs(a_arr - b_arr)
    if method:
        return np.sqrt(np.power(dis_arr, 2).sum())
    return np.sqrt(dis_arr.sum())
```

### 2. K均值聚类

原理：假设数据集合为(𝒙𝟏, 𝒙𝟐, ⋯ , 𝒙𝒏) ，并且每个样本𝒙𝒊为𝒅维的向量，K-means聚类目标，在给定分类组数𝐤(𝒌 ≤ 𝒏) 值的条件下，将原始数据分成𝐤类：𝑺 = {𝑺𝟏, 𝑺𝟐, ⋯ , 𝑺𝒌}
在数值模型上，即对以下表达式求最小值：$$min_s\sum^k_{i=1}\sum_{x\in S_i}||x-\mu_i||^2$$，其中$$\mu_i$$是第i个聚类的中心

算法流程：

1. 随机选取K个对象作为初始聚类中心；
2. 更新中心点：将数据样本集合中的样本按照最小距离原则分配到最邻近聚类；
3. 计算新的中心点：根据聚类的结果，重新计算K个聚类的中心，并作为新的聚类中心；、
4. 重复步骤3直到聚类中心不再变化。

### 梯度下降法

已知梯度的负方向为最快下降方向。取$$\Delta x_k=-\alpha \bigtriangledown f(x_k),(\alpha>0)$$
可得$$x_{k+1}=x_k-\alpha \bigtriangledown f(x_k)$$

```python
import numpy as np
import matplotlib.pyplot as plt
def cost_function(theta, X, y):
    diff = np.dot(X, theta) - y
    return (1./2*n) * np.dot(np.transpose(diff), diff)# n是维数
def gradient_function(theta, X, y):
	diff = np.dot(X, theta) - y
	return (1./n) * np.dot(np.transpose(X), diff)#n是维数
def gradient_descent(X, y, eta): # theta0
	theta = np.array([1, 1]).reshape(2, 1)
    gradient = gradient_function(theta, X, y)
	while not np.all(np.absolute(gradient) <= 1e-5):
		theta = theta - eta* gradient
		gradient = gradient_function(theta, X, y)
	return theta
```
